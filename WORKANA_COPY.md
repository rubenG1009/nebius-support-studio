# Workana project text — review before posting

## Title

Customer Support Assistant with Document-Based Drafts and Human Review

## Short description

I built a local support workflow that turns customer questions into draft replies grounded in a company's policy documents. It retrieves relevant passages, shows the source behind each answer, and lets an agent edit the reply before approving it. The demo works without an AI account; an optional Nebius Token Factory integration adds live model-generated drafts with token and latency tracking.

## What this demonstrates

- Python API and SQLite document search.
- Source-backed response generation and validation.
- Human review workflow with separate original and approved text.
- Optional AI-provider integration with retry and a local daily call limit.

## Honest scope

Portfolio prototype with fictional shop data. No customer deployment, automatic sending, paid client outcome or Nebius certification is claimed. Live Nebius inference requires an API key and has not been demonstrated here.

Python · FastAPI · SQLite · AI integration · Customer support automation · RAG fundamentals
